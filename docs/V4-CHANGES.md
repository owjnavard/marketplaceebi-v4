### درباره نقشه

`TILE_URL` در `MapPicker.tsx` روی OpenStreetMap تنظیم شده. اگر روی
هاست ایرانی کند بود، فقط همین یک ثابت را به سرویس داخلی (نشان،
پارسی‌مپ) تغییر دهید.

اگر کاشی‌ها بارگذاری نشوند، نقشه به یک شبکه مختصاتی ساده برمی‌گردد و
**انتخاب موقعیت همچنان کار می‌کند**. متن راهنما هم به کاربر نشان داده
می‌شود.

## صفحه استعلام‌ها (پنل خریدار و فروشنده)

یک صفحه مشترک با prop نقش: `src/pages/shared/Inquiries.tsx`

| خواسته | وضعیت |
|---|---|
| دو نوع نمایش (کارت / ردیف) | ✅ کلید تغییر نما |
| شش وضعیت | ✅ پیش‌نویس، ارسال شده، در انتظار پیشنهاد، پیشنهاد دریافت شد، تأیید شد، آرشیو شده |
| فیلتر وضعیت | ✅ با شمارنده هر وضعیت |
| دکمه مشاهده و ویرایش با قابلیت آرشیو | ✅ |
| فروشنده پیشنهاد رد یا ثبت کند | ✅ تب «پیشنهادها» |
| تغییرات فروشنده برای خریدار مشخص و قابل تأیید یا رد | ✅ سیستم `Amendment` |
| فروشنده کالاهای خریدار را ببیند و تغییر دهد | ✅ اگر خریدار اجازه داده باشد |
| فروشنده هر دو قیمت را ببیند | ✅ ستون «قیمت خریدار» و «قیمت شما» با محاسبه سود |
| خریدار مشخص کند فروشنده اجازه تغییر دارد یا نه | ✅ `Inquiry.allowSellerEdit` |

**نکته مهم درباره تغییرات فروشنده:** تغییرات فروشنده هرگز مستقیم روی
استعلام اعمال نمی‌شوند. سیستم تفاوت اقلام فعلی با اقلام اصلی را حساب
می‌کند و به‌صورت یک «پیشنهاد تغییر» با فهرست دقیق قبل/بعد برای خریدار
می‌فرستد. فقط با تأیید خریدار اعمال می‌شود.

## آنچه بک‌اند باید اضافه کند

```sql
ALTER TABLE products
  ADD COLUMN stage ENUM('any','survey','steelwork','rails','doors',
                        'mechanical','revision','commissioning','standard') DEFAULT 'any';

ALTER TABLE inquiries
  MODIFY status ENUM('draft','sent','awaiting','offered','accepted','archived'),
  ADD COLUMN allow_seller_edit BOOLEAN DEFAULT 1;

CREATE TABLE inquiry_amendments (
  id, inquiry_id FK, seller_id FK, note TEXT,
  status ENUM('pending','accepted','rejected'), created_at
);
CREATE TABLE amendment_changes (
  id, amendment_id FK, line_id, field ENUM('quantity','product','removed','added'),
  before_value, after_value
);

CREATE TABLE order_evidence (
  id, order_id FK, status, kind ENUM('waybill','photo','note'),
  reference, note TEXT, created_at
);

CREATE TABLE commitment_templates (
  id, title, default_side ENUM('buyer','seller'),
  systems JSON, from_parts_total BOOLEAN, sort_order
);
```

**دو نکته امنیتی:**

۱. `partner_discount` نباید در پاسخ API به کاربری که فروشنده تأییدشده
نیست بیاید.

۲. `allow_seller_edit` باید **سمت سرور** هم بررسی شود. اگر false باشد،
درخواست ویرایش اقلام از سمت فروشنده باید با خطای ۴۰۳ رد شود — غیرفعال
بودن دکمه در رابط کاربری کافی نیست.
