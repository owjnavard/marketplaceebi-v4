# ویرایش‌های نسخه ۶ (بر اساس هفت اسکرین‌شات)

## ۱. جدول توقف‌ها — کنترل پر کردن ستون
نوار جداگانه بالای جدول حذف شد. حالا کنار عنوان هر ستون یک **آیکون
گرد** هست که با کلیک، یک ورودی کوچک باز می‌کند: عدد را می‌زنید و
«اعمال». با Enter هم اعمال می‌شود و با Escape بسته.

## ۲. لیست قطعات — جای دکمه «افزودن قلم»
دکمه از لبه دور صفحه به داخل سربرگ «سایر لوازم» منتقل شد و کلیکش دیگر
باعث باز و بسته شدن بخش نمی‌شود.

## ۳. راهنمای تنظیمات — حذف فهرست کناری
ستون فهرست موضوعات برداشته شد و راهنما تمام‌عرض نمایش داده می‌شود.
راهنما همیشه با آیکون کنار خود تنظیم باز می‌شود، پس فهرست تکراری بود.

## ۴. نحوه پرداخت — انتخاب همزمان چند روش
`method` به `methods` تبدیل شد و حالا می‌توانید **نقدی + اقساط + چک** را
با هم انتخاب کنید. هر روش فیلد مخصوص خودش را می‌آورد:

- اقساط → تعداد اقساط
- چک → مدت چک
- هرکدام از این دو → درصد پیش‌پرداخت

اگر هیچ روشی انتخاب نشود، هشدار داده می‌شود.

## ۵. نام محصول — کاملاً خودکار
دکمه «خودکار» حذف شد. نام همیشه از **دسته‌بندی + ویژگی‌ها + برند** ساخته
می‌شود و ورودی دستی ندارد. تا وقتی ویژگی‌ها خالی باشند، متن راهنما
نمایش داده می‌شود.

## ۶. قیمت‌گذاری — حذف دکمه سوم
دکمه «قیمت همکاری» از نحوه قیمت‌گذاری حذف شد. حالا دو گزینه است:
**قیمت مشخص** و **استعلامی**.

پله‌های قیمت به‌صورت یک **تیک زیر «قیمت مشخص»** آمده‌اند. با روشن کردنش
جدول پله‌ها باز می‌شود.

> قیمت همکاری همان‌جا به‌صورت یک کادر جدا (درصد تخفیف) باقی ماند، چون
> یک تخفیف است نه یک روش قیمت‌گذاری. در مدل داده `pricingMode` هنگام
> ذخیره به‌طور خودکار `tiered` می‌شود اگر پله تعریف شده باشد.

## ۷. ثبت محصول — سه مرحله‌ای

| مرحله | محتوا |
|---|---|
| ۱ | اطلاعات پایه، ویژگی‌های دسته، تصاویر |
| ۲ (اختیاری) | جدول مشخصات فنی، آپلود فایل دیتاشیت |
| ۳ | قیمت‌گذاری |

نوار مراحل بالای فرم است و می‌شود مستقیم روی هر مرحله کلیک کرد. در
مرحله ۱ دکمه «رد کردن مرحله اختیاری» مستقیم به قیمت‌گذاری می‌برد.
کارت موجودی و دکمه‌های ذخیره در همه مراحل کنار صفحه می‌مانند.

**آپلود تصویر و دیتاشیت** در حالت دمو فقط نام فایل را ثبت می‌کند. هنگام
وصل شدن به لاراول، فقط باید فایل ارسال و آدرس برگردانده شود؛ ساختار
داده و رابط کاربری آماده است.

## آنچه بک‌اند باید تغییر دهد

```sql
-- روش پرداخت حالا چندتایی است

  DROP COLUMN payment_method,
  ADD COLUMN payment_methods JSON,
  ADD COLUMN installment_months TINYINT,
  ADD COLUMN cheque_months TINYINT;
```
