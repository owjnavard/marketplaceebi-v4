# آسانسور مارکت — فرانت‌اند

بازار تخصصی قطعات، تجهیزات و خدمات آسانسور. اپلیکیشن تک‌صفحه‌ای فارسی (RTL)
با Vite + React 19 + TypeScript + Tailwind v4، ساخته‌شده برای اجرا روی
**هاست اشتراکی cPanel** بدون نیاز به Node.

## اجرا روی سیستم خودتان

```bash
npm install
npm run dev        # http://localhost:5173
```

بدون هیچ تنظیمی، اپ با دیتای نمونه داخلی بالا می‌آید و همه صفحه‌ها و
پنل‌ها کار می‌کنند. تغییراتی که می‌دهید (ثبت محصول، پیشنهاد قیمت، سفارش)
در `localStorage` می‌ماند.

برای پاک کردن دیتای دمو، در کنسول مرورگر:

```js
localStorage.clear(); location.reload()
```

## ساخت خروجی

```bash
npm run build      # خروجی در پوشه dist
npm run preview    # تست خروجی قبل از آپلود
```

## آپلود روی cPanel

۱. `npm run build` را اجرا کنید.
۲. **محتویات داخل** پوشه `dist` را در `public_html` آپلود کنید — نه خود پوشه را.
۳. مطمئن شوید فایل `.htaccess` هم منتقل شده است. در File Manager سی‌پنل از
   منوی Settings گزینه **Show Hidden Files** را روشن کنید، وگرنه این فایل
   را نمی‌بینید و بدون آن، رفرش کردن صفحات داخلی خطای ۴۰۴ می‌دهد.

ساختار نهایی روی سرور:

```
public_html/
├── .htaccess
├── index.html
├── favicon.svg
├── fonts/Vazirmatn-var.woff2
└── assets/…
```

### نصب در زیرپوشه

اگر سایت باید روی `example.com/shop/` بالا بیاید، دو جا را عوض کنید:

- در `vite.config.ts` مقدار `base` را به `'/shop/'` تغییر دهید
- در `.htaccess` مقدار `RewriteBase` را به `/shop/` تغییر دهید

## وصل کردن بک‌اند لاراول

فایل `.env` بسازید (از روی `.env.example`):

```env
VITE_API_URL=https://example.com/api
```

دوباره build بگیرید. از این لحظه تمام فراخوانی‌ها به‌جای دیتای نمونه، روی
API واقعی می‌روند. **هیچ کد کامپوننتی نیاز به تغییر ندارد** — همه چیز از
`src/lib/api/index.ts` عبور می‌کند.

فهرست کامل مسیرها و اسکیمای پیشنهادی دیتابیس: [`docs/API.md`](docs/API.md)

## ساختار پروژه

```
src/
├── lib/api/          لایه دیتا — تنها نقطه تماس با بک‌اند
│   ├── types.ts      مدل دامنه (منبع حقیقت)
│   ├── seed.ts       دیتای نمونه حالت دمو
│   └── index.ts      فساد api + کلاینت HTTP
├── lib/labels.ts     همه برچسب‌های فارسی و رنگ وضعیت‌ها
├── store/            zustand — احراز هویت، سبد، علاقه‌مندی، اعلان
├── components/       کیت رابط کاربری و اجزای مشترک
├── features/rfq/     موتور لیست قطعات و نقشه برش چاه
├── layouts/          پوسته عمومی و پوسته پنل‌ها
└── pages/            public / buyer / seller / admin
```

## نقش‌ها و صفحه‌ها

در صفحه ورود، نقش را انتخاب کنید و **هر کد ۵ رقمی** را وارد کنید. داخل
پنل هم می‌توانید از منوی کناری بین سه نقش جابه‌جا شوید.

| نقش | مسیر | امکانات |
|---|---|---|
| خریدار | `/panel` | استعلام‌ها، مقایسه پیشنهادها و پذیرش، سفارش‌ها، علاقه‌مندی، پروفایل |
| فروشنده | `/seller` | محصولات، ثبت/ویرایش کالا، پاسخ به استعلام، سفارش‌ها، اطلاعات فروشگاه |
| مدیر | `/admin` | تأیید فروشنده و محصول، دسته‌بندی و ویژگی‌ها، استعلام، سفارش، کمیسیون، کاربران |

بخش عمومی: خانه، کاتالوگ با فیلتر، صفحه محصول، مقایسه، سبد، تسویه،
ویزارد استعلام پروژه، فروشندگان، بلاگ.

## سه حالت قیمت‌گذاری

هسته این مارکت‌پلیس همین است و هر حالت شکل بصری جدا دارد:

| حالت | رفتار | نمایش |
|---|---|---|
| `fixed` | افزودن مستقیم به سبد | قیمت با عدد درشت |
| `quote` | فقط درخواست قیمت | فیلد هاشورخورده به‌جای عدد |
| `tiered` | قیمت تابع تعداد | نردبان پله‌ها؛ پله بدون قیمت ← استعلام |

منطق انتخاب قیمت در `unitPriceFor()` داخل `src/store/index.ts` است.
اقلامی که در تعداد انتخابی قیمت ندارند، در سبد از مبلغ قابل پرداخت جدا
می‌شوند و به مسیر استعلام می‌روند.

## تصمیم‌های فنی

**چرا SPA و نه Next.js؟** هاست اشتراکی cPanel فقط PHP و MySQL دارد؛
رندر سمت سرور Node لازم دارد که در دسترس نیست. خروجی استاتیک روی همان
هاست و کنار لاراول اجرا می‌شود.

**فونت خودمیزبان.** Vazirmatn به‌صورت فایل variable در `public/fonts`
است، نه CDN — چون CDNهای خارجی از ایران کند یا مسدودند.

**بدون عکس محصول.** هر دسته یک نقشه شماتیک SVG دارد
(`components/PartSchematic.tsx`). سریع است، لینک خراب ندارد، و زبان بصری
یک کاتالوگ فنی را می‌سازد نه فروشگاه لوازم خانگی. اگر بعداً عکس واقعی
داشتید، فیلد `images` در مدل محصول از قبل آماده است.

**Code splitting روی هر روت.** اولین بازدید فقط کد صفحه اصلی را می‌گیرد؛
پنل‌ها تا وارد نشوید دانلود نمی‌شوند.

## عملکرد

خروجی build، فشرده با gzip:

| بخش | حجم |
|---|---|
| React + Router + هسته | حدود ۱۰۸ کیلوبایت |
| CSS کل سایت | حدود ۹ کیلوبایت |
| هر صفحه | ۱ تا ۸ کیلوبایت |
| فونت | ۱۰۹ کیلوبایت (یک‌بار، کش یک‌ساله) |

`.htaccess` تحویلی، gzip/brotli و کش یک‌ساله فایل‌های hash‌دار را روشن
می‌کند و `index.html` را کش نمی‌کند تا نسخه جدید بلافاصله دیده شود.
